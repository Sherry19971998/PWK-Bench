# Data

Bundled cohorts for the variant domain (frozen + live) and the SPHERE second
domain. "Synthetic" does not mean the same thing across these — read the
table below before running anything.

## Layout

```text
data/
├── sample/
│   ├── cohort_variant_synthetic.parquet   fully synthetic toy cohort (--demo only)
│   ├── cohort_full_real.parquet           real 491-variant ClinVar cohort (main results)
│   ├── cohort_clinvar_real.parquet        intermediate: real ClinVar labels only
│   ├── clinvar_real_filtered.parquet      intermediate: post >=2-star filter
│   └── uniprot_domains.json               PM1 domain annotation source
├── masked/
│   ├── cohort_full_real_masked_coords.parquet    RQ3: consequence + coordinate masked
│   └── cohort_full_real_masked_p_level.parquet   RQ3: consequence (p.-level) masked only
└── sphere/                                SYNTHETIC ADRC SPHERE release (second domain)
```

## `sample/` — variant cohorts

| File | What it is | Used for |
|---|---|---|
| `cohort_variant_synthetic.parquet` | **Fully synthetic** toy cohort: fabricated values, not real variants. | `--demo` only — a $0, no-API-key check that the *pipeline* runs. Numbers from `--demo` are illustrative and are **never** the paper's results. |
| `cohort_full_real.parquet` | **Fully real**, already-annotated 491-variant cohort: real ClinVar (≥2-star) labels, real PVS1/PM2 for all 491 variants, real PP3/PM1 (AlphaMissense/UniProt) for the 80 missense variants those categories apply to. **Already bundled — no fetch step needed.** | Real runs (`scripts/variant/README.md`, `scripts/live/README.md`). This is what the paper's headline numbers are computed from. |

Verify directly:

```bash
python3 -c "
import pandas as pd
df = pd.read_parquet('data/sample/cohort_full_real.parquet')
print(df.shape, df.source.value_counts().to_dict())
print('missense w/ PP3 defined:', int((df.is_missense & df.PP3__defined).sum()))
"
# -> (491, 15) {'REAL': 491}
# -> missense w/ PP3 defined: 80
```

## `masked/` — RQ3 closed-book masking check

Two progressively-masked variants of the real cohort, used only by the
closed-book memorization probe (see
[`scripts/live/README.md`](../scripts/live/README.md)), never by the main
frozen or live sweeps. `cohort_full_real_masked_coords.parquet` sets
`clinvar_name == variant_id` (bare genomic coordinates, no HGVS transcript
name) — the strongest mask. `cohort_full_real_masked_p_level.parquet` masks
only the protein-consequence token (`p.Arg213Ter` → `p.?`), a lighter mask.

## `sphere/` — second domain

Stanford ADRC's own **SPHERE** release — officially synthetic patient
records (ids are literally `Synthetic537`, ...) generated by ADRC for
methods development. Not ClinVar, not this paper's clinical claim. See
[`scripts/sphere/README.md`](../scripts/sphere/README.md) for the full
methodology, cost model, and caveats.

## In short

`--demo` needs no key and takes ~30s, but only checks that the code runs —
it is not a smaller version of the paper's real numbers. To reproduce those,
point at `cohort_full_real.parquet` with real models (API keys); nothing
needs to be fetched or rebuilt first.
